# 미등록(Unlisted) 배포 체크리스트

## 업로드 전

- [ ] 교내 시험 사용자 2~3명에게 전체 학기 입력 테스트
- [ ] 시험용이 아닌 실제 문의 이메일 결정
- [ ] `PRIVACY.md`의 문의 항목에 이메일 반영
- [ ] 개인정보 처리 안내를 공개 URL(GitHub Pages, 학교 홈페이지 등)에 게시
- [ ] 개인정보 처리방침 공개 URL 확인
- [x] 교사 이름·학생 정보가 보이지 않는 640×400 스토어 스크린샷 준비
- [ ] 확장 프로그램 버전과 ZIP 파일명 확인

## Chrome 개발자 대시보드

- [ ] 개발자 계정 등록
- [ ] 새 항목 추가 후 배포 ZIP 업로드
- [ ] 제품명·요약·상세 설명 입력
- [ ] 카테고리를 생산성으로 선택
- [x] 128×128 아이콘, 440×280 홍보 이미지, 640×400 스크린샷 준비
- [ ] 준비된 아이콘과 이미지 파일을 대시보드에 등록
- [ ] 단일 목적 및 권한 사유 입력
- [ ] 개인정보 공개 문항 입력
- [ ] 개인정보 처리방침 URL 입력
- [ ] 공개 범위를 `미등록(Unlisted)`으로 선택
- [ ] 심사자 테스트 안내 입력
- [ ] 검토 제출

## 승인 후

- [ ] 미등록 설치 링크를 교내 시험 사용자에게 먼저 공유
- [ ] 설치 및 실제 시간표 입력 재확인
- [ ] 교직원에게 설치 링크와 짧은 사용 안내 배포
- [ ] 업데이트 시 버전을 올려 새 ZIP 제출
