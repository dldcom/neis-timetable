사용 방법 1 / 4

연간시간표 불러오기

1. 연간시간표 불러오기

EasyEdu에서 출력한 HWPX를 권장합니다. DAT도 사용할 수 있습니다.

아직 파일을 선택하지 않았습니다.

2. 주차 미리보기

일반 전담 특별실 행사표시
DAT를 선택하면 표시됩니다.

3. 나이스 화면 확인

학급시간표 관리 화면에서 점검하세요.

4. 교사 선택 기준

HWPX에서 초록 글씨인 과목은 전담 교사를, 초록 글씨가 아니면 담임을 선택합니다.

5. 학기 전체 입력

입력 중에는 나이스 탭과 이 패널을 닫지 마세요.
