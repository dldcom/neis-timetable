# 개인정보 처리 안내

최종 수정일: 2026년 8월 25일

## 1. 도구의 성격

`시간표 자동 입력기`는 EasyEdu에서 출력한 연간시간표 HWPX 파일을 사용자가 로그인한 시도교육청 나이스 학급시간표 관리 화면에 입력하도록 돕는 비공식 Chrome 확장 프로그램입니다. EasyEdu, 나이스, 교육부 또는 시도교육청이 제작하거나 보증한 공식 프로그램이 아닙니다.

## 2. 수집하는 개인정보

이 확장 프로그램은 개발자 또는 제3자의 서버로 개인정보를 수집하거나 전송하지 않습니다.

- 사용자 계정, 비밀번호 및 인증서 정보를 수집하지 않습니다.
- 나이스 로그인 쿠키를 읽거나 외부로 전송하지 않습니다.
- 선택한 HWPX/DAT 파일을 외부 서버에 업로드하지 않습니다.
- 광고, 분석 도구, 사용자 추적 도구를 사용하지 않습니다.

## 3. 로컬에서 처리하는 정보

사용자가 직접 선택한 HWPX/DAT 파일은 해당 사용자의 브라우저 메모리에서만 분석됩니다. 분석된 시간표는 사용자가 이미 로그인한 시도교육청 나이스 학급시간표 관리 화면에 입력하는 데만 사용됩니다.

확장 프로그램은 나이스 화면에서 다음 정보를 일시적으로 확인합니다.

- 선택된 주차
- 학급시간표 셀의 기존 과목
- 학급시간표 셀에 함께 표시된 교사 이름(화면에 포함된 경우)
- 저장 확인 및 저장 완료 알림

이 정보는 자동 입력과 충돌 확인을 위해 현재 브라우저 탭 안에서만 사용되며 별도로 보관하거나 전송하지 않습니다.

## 4. 데이터 보관 및 공유

확장 프로그램은 시간표, 나이스 화면 정보 또는 사용자 식별 정보를 자체 저장소에 보관하지 않습니다. 개발자나 제3자에게 데이터를 판매하거나 공유하지 않습니다.

## 5. Chrome 권한 사용 목적

- `sidePanel`: 시간표 파일 선택과 입력 제어 화면을 Chrome 사이드 패널에 표시합니다.
- `activeTab`: 사용자가 현재 열어 둔 시도교육청 나이스 학급시간표 관리 탭을 확인합니다.
- `scripting`: 화면 제어 코드가 연결되지 않은 경우 사용자가 활성화한 시도교육청 나이스 탭에 해당 코드를 다시 연결합니다.
- 시도교육청별 `https://{지역코드}.neis.go.kr/*`: 나이스 학급시간표 관리 화면을 확인하고 사용자가 승인한 시간표 입력·저장 작업을 수행합니다.

## 6. 사용자 통제

시간표 파일은 사용자가 직접 선택하며, 기존 수업이 발견되거나 학기 전체 입력을 시작할 때 확인을 요청합니다. 사용자는 언제든 확장 프로그램을 비활성화하거나 삭제할 수 있습니다.
