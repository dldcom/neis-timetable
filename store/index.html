개인정보 처리 안내

최종 수정일: 2026년 8월 25일

이 확장 프로그램은 EasyEdu, 나이스, 교육부 또는 시도교육청이 제작하거나 보증한 공식 프로그램이 아닙니다.

수집 및 전송

개발자 또는 제3자의 서버로 개인정보를 수집하거나 전송하지 않습니다. 계정·비밀번호·인증서·로그인 쿠키를 수집하지 않으며, 사용자가 선택한 HWPX/DAT 파일을 외부 서버에 업로드하지 않습니다. 광고, 분석 및 사용자 추적 도구도 사용하지 않습니다.

브라우저 안에서 처리하는 정보

선택한 시간표 파일은 브라우저 메모리에서만 분석됩니다. 확장 프로그램은 자동 입력과 충돌 확인을 위해 시도교육청 나이스 화면의 선택 주차, 기존 과목, 화면에 포함된 교사 이름, 저장 확인 및 저장 완료 상태를 일시적으로 확인할 수 있습니다. 이 정보는 저장하거나 외부로 전송하지 않습니다.

Chrome 권한

  • sidePanel: 파일 선택과 입력 제어 화면 표시
  • activeTab: 사용자가 활성화한 시도교육청 나이스 탭 확인
  • scripting: 로컬 화면 제어 코드 재연결
  • 시도교육청별 neis.go.kr 도메인: 학급시간표 확인, 입력 및 저장

사용자 통제

파일은 사용자가 직접 선택하며 기존 수업 변경과 학기 전체 입력 전 확인을 요청합니다. 사용자는 언제든 확장 프로그램을 비활성화하거나 삭제할 수 있습니다.
