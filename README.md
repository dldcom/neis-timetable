# 시간표 자동 입력기

## 현재 버전

`0.9.9` 미등록 웹 스토어 배포 준비판이다. 로그인은 사용자가 직접 하며, 학기 전체 입력에서는 주차별 저장을 자동 처리한다.

기능:

- 기존 입력 화면을 항상 메인으로 표시
- 오른쪽 위 `사용 방법` 버튼을 누르면 실제 입력란과 버튼이 빨간색으로 반짝이는 4단계 튜토리얼 실행
- EasyEdu에서 출력한 연간시간표 `.hwpx` 직접 분석(권장)
- 5·6학년 실과(`실`) 인식 및 나이스 `실과` 입력
- 1·2학년 통합교과 `바·슬·즐`을 `바른 생활·슬기로운 생활·즐거운 생활`로 입력
- 초록 글씨가 없는 학기는 전담 수업 없음 확인 후 모든 과목을 담임 수업으로 처리
- 한 HWPX에 1·2학기가 함께 있으면 나이스에서 조회한 학년도·학기에 맞는 표를 자동 선택
- HWPX와 나이스의 1주차 날짜 범위를 비교해 다른 학기나 잘못된 파일 입력 방지
- 로컬 `N학기연간시간표.dat` 직접 분석(고급 입력 방식)
- 주차별 시간표 미리보기
- 나이스 학급시간표 관리 화면 구조 점검
- 기존 값이 있으면 충돌 위치를 경고하고 사용자가 확인한 경우에만 변경
- 한 번의 버튼으로 학기 전체 주차 입력
- 학기 전체 입력에서는 각 주차 입력 후 저장하고, 저장 완료를 확인한 뒤 다음 주차로 이동
- 작은 화면에서 주차·교시 행이 가려지면 해당 표를 자동 스크롤하여 목표 행을 표시
- 사전 충돌 검사는 같은 교시의 월~금 셀을 묶어 확인하고, 스크롤이 필요할 때만 대기

## 설치

1. Chrome 주소창에서 `chrome://extensions`를 연다.
2. 오른쪽 위의 `개발자 모드`를 켠다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누른다.
4. 이 폴더를 선택한다.

## 화면 안 사용 방법

사이드 패널 오른쪽 위의 `사용 방법`을 누르면 다음 순서로 실제 조작할 부분이 반짝인다. 해당 작업이 완료되어야 `다음` 버튼이 활성화된다.

```text
HWPX 선택 → 나이스 화면 점검 → 교사 순서 확인 → 학기 전체 입력
```

HWP 파일을 선택하면 다음 안내를 표시하고 파일을 읽지 않는다.

```text
HWP 파일은 읽을 수 없습니다.
한글에서 파일을 연 뒤 파일 → 다른 이름으로 저장 → HWPX로 저장해 주세요.
```

```text
C:\EasyeduTogether\Easyedu2026\tools\neis-timetable-extension
```

5. 나이스에 직접 로그인하고 `학급시간표 관리` 화면을 연다.
6. 확장 프로그램 설치 전에 나이스 화면이 열려 있었다면 페이지를 한 번 새로고침한다.
7. Chrome 도구 모음에서 확장 프로그램 아이콘을 눌러 사이드 패널을 연다.

## 사용 순서

1. 사이드 패널에서 EasyEdu가 출력한 `연간시간표_학년반.hwpx`를 선택한다. 1·2학기가 한 파일에 함께 있어도 된다. DAT를 알고 있는 경우에는 `N학기연간시간표.dat`도 선택할 수 있다.
2. `현재 화면 점검`을 누른다.
3. 과목 입력칸을 우클릭해 전담 과목의 교사 순서를 확인하고, 같은 순서를 선택한 뒤 체크한다.
4. `학기 전체 시간표 입력`을 누른다.
5. 최종 확인창을 확인한다.

## 학기 전체 입력

현재 나이스 화면은 한 주 입력 후 다른 주차로 이동하기 전에 `저장`해야 한다. 학기 전체 입력은 아래 순서로 주차마다 저장한다.

자동화 순서는 다음과 같다.

```text
주차 입력 → 저장 클릭 → 확인창 처리 → 저장 성공 확인 → 다음 주차 이동
```

저장 실패나 완료 여부를 확인할 수 없는 경우에는 다음 주차로 이동하지 않고 즉시 중지해야 한다.

1. `학기 전체 시간표 입력`을 누른다.
2. 확장 프로그램이 모든 주차의 기존 입력을 조사한다.
3. 최종 확인창에서 계속 여부를 선택한다.
4. 확인하면 1주차부터 입력하고 주차마다 저장한다.
5. 완료 후 나이스 화면에서 결과를 확인한다.

입력 도중 오류가 발생하면 해당 주차에서 중지하고 완료된 주차와 차시는 진행 기록에 남긴다. 다시 실행하면 기존 입력 경고 후 이어서 덮어쓸 수 있다.

## 교사 선택 기준

전담 수업이 있는 과목은 나이스 선택창에 담임과 전담 교사가 함께 표시될 수 있다. 기본값은 `첫 번째 담임 / 두 번째 전담`이다. 순서가 반대인 학교는 `첫 번째 전담 / 두 번째 담임`을 선택한다.

- HWPX에서 초록 글씨인 과목: 전담 선택지
- 초록 글씨가 아닌 과목: 담임 선택지

전체 입력 전에 실제 선택 순서가 맞는지 반드시 확인한다.

## 안전 동작

- `https://goe.neis.go.kr/*`에서만 작동한다.
- 로그인 정보, 쿠키, 인증서에 접근하지 않는다.
- HWPX와 DAT는 외부로 전송하지 않고 브라우저 메모리에서만 읽는다.
- 기존 값이 있는 주차는 충돌 개수와 위치를 보여주고 변경 여부를 확인한다. 취소하면 수정하지 않고, 확인하면 HWPX 시간표로 변경한다.
- 학기 전체 입력은 매 주차를 자동 저장한다.
- 화면 구조를 찾지 못하거나 선택지가 예상과 다르면 즉시 중단한다.

## 알려진 제약

- 주차 목록의 해당 행이 가상 스크롤 바깥에 있으면 먼저 사용자가 그 주차가 보이도록 스크롤해야 할 수 있다.
- 나이스 화면 구조가 바뀌면 DOM 선택 기준을 다시 확인해야 한다.
- 나이스 가상 그리드에서 낮은 교시 입력 후 1교시 행이 사라지는 일을 피하도록 `1교시 월~금 → 2교시 월~금` 순서로 입력한다.
- 전담 과목의 교사 선택 순서는 학교와 담당자 구성에 따라 다를 수 있다.
- HWPX에 여러 학기가 있으면 나이스의 현재 학년도·학기를 읽어 자동 선택한다. 학교별 학기 시작일은 고정하지 않으며, HWPX 1주차의 수업 기간이 나이스 1주차 날짜 범위와 겹치는지 확인한다.
- HWPX `header.xml`의 문자 속성과 각 과목 셀의 `charPrIDRef`를 연결해 실제 초록 글씨 여부를 판정한다.
- `대-체-휴-일`처럼 휴업일 문구가 셀마다 한 글자씩 들어간 경우 빨간 글씨를 수업에서 제외해, 가운데 `체`를 체육으로 잘못 집계하지 않는다.

연결 오류가 발생하면 확장 프로그램이 `content.js`를 현재 나이스 탭에 자동으로 주입한 뒤 한 번 더 시도한다. 확장 프로그램 권한이 변경된 직후에는 `chrome://extensions`에서 확장 프로그램을 새로고침하고 나이스 페이지도 새로고침한다.
