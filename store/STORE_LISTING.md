# Chrome 웹 스토어 등록 문안

## 제품명

시간표 자동 입력기

## 요약 설명

EasyEdu HWPX 연간시간표를 경기 나이스 학급시간표 관리 화면에 주차별로 입력하고 저장하는 비공식 교사용 도구입니다.

## 상세 설명

EasyEdu에서 출력한 연간시간표를 나이스에 반복해서 입력하는 작업을 줄여 주는 교사용 Chrome 확장 프로그램입니다.

주요 기능:

- HWPX 연간시간표를 브라우저에서 직접 분석
- 주차별 시간표 미리보기
- 영어·체육 담임/전담 구분 반영
- 기존 입력 시간표 충돌 사전 확인
- 화면 밖 주차와 교시 자동 스크롤
- 각 주차 입력 후 저장 완료를 확인하고 다음 주차로 이동
- 실제 버튼이 빨간색으로 반짝이는 단계별 사용 안내

파일과 시간표 정보는 사용자의 브라우저 안에서만 처리하며 개발자 서버로 업로드하지 않습니다. 사용자가 직접 나이스에 로그인한 뒤 `학급시간표관리` 화면에서 사용해야 합니다.

이 확장 프로그램은 EasyEdu, 나이스, 교육부 또는 경기도교육청이 제작하거나 보증한 공식 프로그램이 아닙니다. 사용자는 학기 전체 입력 전 시험 입력 결과를 확인하고, 완료 후 나이스 시간표를 직접 검토해야 합니다.

지원 파일:

- HWPX: 권장
- DAT: 고급 사용자용
- HWP: 지원하지 않음. 한글에서 HWPX로 다시 저장해야 함

## 단일 목적 설명

사용자가 선택한 EasyEdu 연간시간표를 사용자가 로그인한 경기 나이스 학급시간표 관리 화면에 입력하고 주차별 저장을 확인하는 기능만 제공합니다.

## 권한 사유

### sidePanel

파일 선택, 미리보기, 시험 입력 및 학기 전체 입력 제어 화면을 나이스 옆에 계속 표시하기 위해 필요합니다.

### activeTab

사용자가 현재 활성화한 경기 나이스 학급시간표 관리 탭을 확인하고 해당 탭에만 명령을 전달하기 위해 필요합니다.

### scripting

확장 프로그램 업데이트나 페이지 새로고침 후 화면 제어 코드가 연결되지 않은 경우, 사용자가 활성화한 경기 나이스 탭에 로컬 패키지의 `content.js`를 다시 연결하기 위해 필요합니다. 원격 코드는 실행하지 않습니다.

### 호스트 권한: https://goe.neis.go.kr/*

경기 나이스 학급시간표 관리 화면의 주차·교시·기존 과목·저장 상태를 확인하고 사용자가 승인한 입력을 수행하기 위해 필요합니다. 다른 웹사이트에서는 작동하지 않습니다.

## 개인정보 공개 답변 초안

- 개인 식별 정보 처리: 예. 시간표 셀에 교사 이름이 표시된 경우 기존 수업 충돌 확인을 위해 브라우저 안에서 일시적으로 읽을 수 있음. 저장·전송하지 않음
- 건강 정보 수집: 아니요
- 금융 및 결제 정보 수집: 아니요
- 인증 정보 수집: 아니요
- 개인 통신 수집: 아니요
- 위치 정보 수집: 아니요
- 웹 기록 수집: 아니요
- 사용자 활동 추적: 아니요
- 웹사이트 콘텐츠 처리: 예. 사용자가 활성화한 경기 나이스 학급시간표 화면의 과목과 저장 상태를 자동 입력 목적으로만 일시적으로 처리
- 데이터 판매 또는 광고 사용: 아니요
- 원격 코드 사용: 아니요

## 심사자 테스트 안내

이 확장 프로그램은 인증이 필요한 경기 나이스 학급시간표 관리 화면에서만 핵심 기능이 작동합니다. 테스트 계정을 제공할 수 없는 경우 다음 내용을 심사 메모에 명시합니다.

1. 확장 프로그램 아이콘을 누르면 사이드 패널이 열립니다.
2. HWPX 파일은 브라우저 내부에서만 분석됩니다.
3. `현재 화면 점검` 이후의 입력 기능은 `https://goe.neis.go.kr/`의 로그인된 `학급시간표관리` 화면을 필요로 합니다.
4. 확장 프로그램에는 외부 서버 요청, 광고, 분석 SDK 및 원격 코드가 없습니다.
