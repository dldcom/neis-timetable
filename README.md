# 시간표 자동 입력기

EasyEdu에서 출력한 연간시간표를 경기 나이스의 학급시간표 관리 화면에 입력해 주는 Chrome 확장 프로그램입니다.

현재 버전은 `0.9.9`입니다. 나이스 로그인은 사용자가 직접 하고, 학기 전체 입력을 시작하면 프로그램이 주차마다 시간표를 입력하고 저장합니다.

> EasyEdu·나이스·교육부·경기도교육청의 공식 프로그램은 아닙니다.

## 주요 기능

- 사이드 패널에서 파일을 고르고 시간표를 미리 봅니다.
- `사용 방법`을 누르면 실제로 조작할 부분을 빨간색 테두리로 표시합니다.
- EasyEdu의 HWPX 연간시간표를 읽습니다. DAT 파일도 불러옵니다.
- 한 파일에 1·2학기가 함께 있어도 나이스에서 조회한 학기와 맞는 표를 찾습니다.
- `실`은 나이스의 `실과`로, 1·2학년의 `바·슬·즐`은 각각 `바른 생활·슬기로운 생활·즐거운 생활`로 입력합니다.
- HWPX에서 초록색 글씨인 과목은 전담 수업으로 처리합니다.
- 기존 수업이 있으면 위치와 개수를 먼저 보여 주고, 확인한 경우에만 바꿉니다.
- 한 번의 버튼으로 학기 전체를 입력하고, 주차마다 저장이 끝난 뒤 다음 주차로 넘어갑니다.
- 화면이 작아 주차나 교시가 가려지면 해당 행을 자동으로 찾습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위에서 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 저장소의 폴더를 선택합니다.
5. 나이스에 로그인한 뒤 `학급시간표 관리` 화면을 엽니다.
6. 확장 프로그램을 설치하기 전에 나이스 화면을 열어 두었다면 페이지를 한 번 새로고침합니다.
7. Chrome 도구 모음의 확장 프로그램 아이콘을 눌러 사이드 패널을 엽니다.

## 사용 방법

사이드 패널 오른쪽 위의 `사용 방법`을 누르면 다음 순서로 안내합니다.

```text
HWPX 선택 → 나이스 화면 점검 → 교사 순서 확인 → 학기 전체 입력
```

### 1. 파일 선택

EasyEdu에서 출력한 `연간시간표_학년반.hwpx`를 선택합니다. 1·2학기가 한 파일에 함께 있어도 됩니다. DAT 파일을 사용할 때는 `N학기연간시간표.dat`를 선택합니다.

HWP 파일은 읽을 수 없습니다. 한글에서 파일을 연 뒤 `파일 → 다른 이름으로 저장 → HWPX`로 저장해 주세요.

### 2. 나이스 화면 점검

나이스에서 학년도·학기·학년·반을 조회한 뒤 `현재 화면 점검`을 누릅니다.

### 3. 교사 순서 확인

나이스 과목 입력칸을 마우스 오른쪽 버튼으로 눌러 교사 선택 순서를 확인합니다. 기본값은 `첫 번째 담임, 두 번째 전담`입니다. 순서가 반대라면 `첫 번째 전담, 두 번째 담임`을 선택하고 체크합니다.

HWPX의 초록색 글씨인 과목은 전담 선택지로, 초록색이 아닌 과목은 담임 선택지로 처리합니다. 초록색 글씨가 하나도 없으면 안내창에서 전담 수업 없이 진행할 수 있습니다.

### 4. 학기 전체 입력

`학기 전체 시간표 입력`을 누르고 최종 확인창에서 계속할지 선택합니다. 기존 수업이 있으면 충돌 위치를 확인한 뒤 진행합니다.

나이스는 한 주 입력을 끝낸 뒤 저장해야 다음 주차로 이동할 수 있습니다. 프로그램은 다음 순서로 처리합니다.

```text
주차 입력 → 저장 → 저장 완료 확인 → 다음 주차 이동
```

입력 중 오류가 나면 해당 주차에서 멈추고, 완료한 주차와 차시는 진행 기록에 남깁니다. 입력이 끝난 뒤에는 나이스 화면에서 결과를 확인해 주세요.

## 개인정보와 안전

- `https://goe.neis.go.kr/*`에서만 작동합니다.
- 로그인 정보, 비밀번호, 쿠키, 인증서에 접근하지 않습니다.
- HWPX와 DAT 파일은 외부 서버로 보내지 않고 브라우저 메모리에서만 읽습니다.
- 화면 구조나 과목 선택지가 예상과 다르면 입력을 멈춥니다.
- 연결 오류가 나면 확장 프로그램을 새로고침한 뒤 나이스 페이지도 새로고침해 주세요.
