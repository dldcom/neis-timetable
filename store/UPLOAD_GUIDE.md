# Chrome 웹 스토어 미등록 배포 절차

## 준비된 파일

- 업로드 ZIP: `../dist/EasyEdu-timetable-helper-0.9.13.zip`
- 스토어 문안: `STORE_LISTING.md`
- 개인정보 안내: `PRIVACY.md`
- 아이콘: `../icons/icon-128.png`
- 작은 홍보 이미지: `assets/promo-440x280.png`
- 스크린샷: `assets/screenshot-main-640x400.png`

## 1. 개인정보 안내 공개

`PRIVACY.md`의 `YOUR_EMAIL@example.com`을 실제 문의 이메일로 바꿉니다. 개인정보 안내를 GitHub Pages, 학교 홈페이지 등 로그인 없이 누구나 열 수 있는 HTTPS 주소에 게시하고 그 URL을 기록합니다.

## 2. 개발자 대시보드에 ZIP 업로드

1. [Chrome 개발자 대시보드](https://chrome.google.com/webstore/devconsole/)에 로그인합니다.
2. 개발자 계정 등록을 완료합니다.
3. `새 항목`을 누릅니다.
4. `EasyEdu-timetable-helper-0.9.13.zip`을 업로드합니다.

ZIP의 루트에는 `manifest.json`이 있으며 실행에 필요한 파일만 들어 있습니다.

## 3. 스토어 등록정보 입력

`STORE_LISTING.md`의 제품명, 요약 설명, 상세 설명을 복사해 입력합니다. 카테고리는 `생산성`, 언어는 `한국어`를 사용합니다.

다음 이미지를 등록합니다.

- 128×128 아이콘
- 440×280 작은 홍보 이미지
- 640×400 실제 화면 스크린샷

## 4. 개인정보 및 권한 입력

`STORE_LISTING.md`의 단일 목적, 권한 사유, 개인정보 공개 답변을 사용합니다. 개인정보 처리방침 URL에는 1단계에서 공개한 HTTPS 주소를 입력합니다.

시간표 셀에 교사 이름이 표시될 수 있으므로 웹사이트 콘텐츠와 해당 화면의 개인 식별 정보가 브라우저 안에서 일시 처리될 수 있음을 숨기지 않습니다. 데이터는 저장하거나 외부로 전송하지 않습니다.

## 5. 공개 범위 설정

배포 탭에서 공개 범위를 `미등록(Unlisted)`으로 선택합니다. 미등록 항목도 Chrome 웹 스토어 정책 심사를 받습니다.

## 6. 심사 제출

심사자 테스트 안내에 `STORE_LISTING.md`의 테스트 안내를 입력한 뒤 검토를 제출합니다. 승인 후 생성된 설치 링크를 먼저 2~3명의 교사에게 공유하여 실제 설치와 입력을 확인합니다.
